A sample application built in 2020 to showcase experience in MVC design and Ruby on Rails. 
##### Stack
Ruby on Rails, PostgreSQL, CarrierWave, ActiveStorage, AWS S3
##### Objective
- Initial requirements needed CarrierWave for photo upload.
- Requirements also included album creation and commenting.
##### Implementation
- Created a user, photo, album, and comment model.
- Built out scaffolded controllers, simple MVC meant minimal configuration.
- Drag-and-drop file upload to AWS S3 using CarrierWave.
- Drag-and-drop file appending for albums.
- Front-end design using Bootstrap.
- Used config.ru for quick deployment to Heroku.
##### Impact & Conclusion
* Job offer at VisualLive secured shortly before final deployment to Heroku.
- Eventual containerization to practice for containerization at work.
- Eventual upgrade from Rails 6 to 7.
- Eventual switch from CarrierWave to ActiveStorage.
